假设失效条件：
- 中国 10 年期国债收益率中枢上/下移超过 100bp → 债券类收益假设须重设。
- 人民币出现单边大幅贬值（年化 >8%）→ 海外资产需拆分汇率损益。
- 通胀中枢回到 4% 以上 → 现金与定存假设需扣实际购买力。
- 日本央行持续加息或货币政策正常化 → 日股收益假设与日元汇率须重估；日经对出口企业盈利与日元贬值高度敏感。

### 关于日本股市的三条特别说明

1. **日经 225 是价格加权指数，不是市值加权。** 高价股对指数的影响被放大，用它代表「日本市场」会失真。能选东证 TOPIX 优先选 TOPIX。
2. **日元汇率是半个仓位。** 人民币投资日股，实际收益 = 日股涨幅 + 日元兑人民币变动。日元长期贬值会吃掉指数涨幅，这部分常常比选股更有决定性。
3. **不能拿「过去两年涨得好」外推。** 日股长期名义回报主要靠企业治理改革与弱日元，两者都不是永续变量；且日本已走出长期通缩，利率方向与过去二十年相反。

## 2. 战术偏离的三个量化指标

### 指标 A：股债性价比（ERP）

```
ERP = (1 ÷ 沪深300 PE_TTM) − 中国10年期国债收益率
```

| ERP 区间 | 含义 | 动作 |
|---|---|---|
| > 5.0pp | 权益显著便宜 | 权益可至区间上沿（+5pp） |
| 2.0–5.0pp | 中性 | 维持目标值 |
| 1.0–2.0pp | 权益偏贵 | 权益压至下沿 |
| < 1.0pp | 极端贵 | 权益降至下沿再减 5pp，多余转入短债 |

### 指标 B：估值分位

目标指数 PE_TTM / PB 的近 10 年历史分位。<30% 分位 → 可上浮；>70% 分位 → 须下调。分位须现查，不得用记忆值。

### 指标 C：极端回撤

某资产自 52 周高点回撤 >25% 且无基本面恶化（盈利未连续两季下修）→ 允许一次性补至**目标值上限**。超出 ±5pp 偏离预算的部分，须在报告中单列理由与退出条件。

这张表是"减 A 股、加美股日经"这个想法必须先过的关：要加的三个市场，YTD 分别涨了 27.3% / 13.9% / 12.8%，PE 19.7 / 31.6 / 24.9；要减的两个市场，YTD 跌了 9.9% / 11.8%，PE 10.6 / 12.9。

**这不等于不该调，但调的理由必须写对。** 如果理由写"美股日经涨得好"，那是动量交易；如果理由写"降低中国权益集中度、降低组合波动"，那是配置纪律——同一个动作，两种性质，后续的持有体验完全不同。后者在回撤期拿得住，前者拿不住。

**代入指标 A（示例推演）：**
```
ERP = 1 ÷ 12.88 − 1.63% = 7.76% − 1.63% = 6.13pp
```
→ 落在 ">5.0pp" 区间，权益可至区间上沿。这个算式的价值在于**方法**：在极低利率环境下，债券的预期回报被压到 2.5% 左右，而权益的盈利收益率可能是它的数倍。但每次都必须用当期真实数据重算，6.13pp 只是那一天的数。

**示例同时示范了负面证据该怎么记：**
- 三个主要风险资产（沪深300、恒指、黄金）年内同时下跌，说明当时处于同步回撤期，波动会放大。
- 黄金自高点回撤 −31%，虽有配置价值，但不宜一次打满，分批进入。
- 便宜只决定赔率，不决定时点。报告里必须同时写清这两层，不能只报喜。
