# 家庭资产配置（IPS 投资政策书）

> 不是"买什么"，而是"钱怎么分、比例带多少、什么条件才动手"。

**English summary.** Builds a family Investment Policy Statement: buckets investable assets by purpose rather than expected return, then outputs target weights with bands, rebalancing triggers, and Monte-Carlo goal-attainment probability. Seven modules, zero dependencies (Python standard library only). Documentation below is Chinese-first; an English-native edition of the same methodology with global asset classes is [family-goal-bucket-planner](https://github.com/yangsssssss/family-goal-bucket-planner).

```
npx skills add https://github.com/yangsssssss/family-asset-allocation
```

## 解决什么问题

大部分"资产配置"输出的是一张比例表，三个月后市场一波动就没人记得当初为什么这么配。本技能产出的是 **IPS（Investment Policy Statement，投资政策书）**——把决策写死在纸面上：每类资产的目标比例与上下限、再平衡的触发阈值、目标达成的概率、以及假设失效的条件。写完能放三年不动，选品每季度换都行。

**核心边界：不产出"推荐买什么"的选品清单。** 选品只到"工具类别 + 筛选标准"，不给具体标的代码，不承诺收益。

## 七个模块

| 模块 | 内容 | 关键产出 |
|---|---|---|
| M1 | 家庭财务体检 | 资产负债表 + 现金流量表，6 项指标对阈值，红黄绿灯 |
| M2 | 风险画像 | 客观能力分 × 主观意愿分，**取两者低值**定档 |
| M3 | 目标与时间分桶 | 应急金 / 3 年内刚性支出 / 5–10 年目标 / 15 年以上长钱 |
| M4 | 战略配置 SAA | 目标比例 + **上下限带**，蒙特卡洛达成率 |
| M5 | 选品映射 | 工具类别 + 筛选门槛 + 费率上限 |
| M6 | 再平衡规则 | ±5pp 或相对偏离 20% 双阈值，写死触发条件 |
| M7 | 保障缺口 | 保额需求法测算，只算缺口不推产品 |

## 三个不常见的设计

**1. 缺失信息用缺省假设填，不反复追问。**
你只说"我有 200 万要配"，它也能跑完——所有估算值会在报告首页的**假设清单**里逐条列出，并标注"改了会影响哪一节"。最多问一轮，绝不逐项盘问。

**2. 储蓄贡献诊断：告诉你什么时候该降波而不是提收益。**
先算储蓄贡献比 `(月储蓄 × 12 × 年限) ÷ 目标金额`。若 >50%，达成主要靠储蓄而非本金增值，此时提高权益比例**反而降低达成率**——因为多出来的波动只产生拖累（volatility drag）。实测：20 年、月投 1.5 万、目标 500 万时，权益 35% / 50% / 65% 对应达成率 97.0% / 95.2% / 93.6%，单调下降。这条会写进报告，而不是用"提高收益"的话术掩盖一次实质的降波决策。

**3. 先做可行性校验，再给比例——三条上限是互相牵制的。**
大多数配置工具会让你直接填比例，填出算不出来的方案。这里会先算：

```
权益上限 = 100% − 债券 − 黄金 − 现金
外币 ≤ 45%  →  A 股 ≥ 权益合计 − 45%
```

所以"A 股低于 10%"和"外币不超 40%"**不能同时成立**（除非把权益压到 55% 以下）。遇到这类冲突，它不会硬凑，而是告诉你放宽哪条、代价是什么：外币 45% 时人民币升值 5% 组合亏 2.25pp，这笔账会单独列出来。跨境资产还会给**建仓阶梯**（目标比例拆三批 + 溢价红线 + 12 个月建仓期限），区分"目标比例"与"已建仓比例"——避免把买不到的仓位当成已配置。

## 产出长什么样

单文件 HTML 的 IPS，固定 10 个区块：假设清单 → 执行摘要（3 条结论 + 配置总表）→ M1 体检 → M2 风险画像 → M3 分桶 → M4 配置与达成概率（含环形图、终值分位图）→ M5 选品映射 → M6 再平衡条款 → M7 保障缺口 → 风险提示与假设失效条件。

## 使用示例

直接说人话即可触发：

- 「我家有 200 万，怎么配置」
- 「帮我做个家庭财务体检」
- 「养老要准备多少钱，现在开始来得及吗」
- 「这份组合要不要再平衡」
- 「保险保额够不够」
- 「给我出一份 IPS 投资政策书」

也可以带参数快速跑蒙特卡洛：

```bash
python3 scripts/monte_carlo.py \
  --initial 105 --monthly 1.2 --years 20 --target 500 \
  --weights "a:8,hk:10,ov:22,jp:13,bond:38,gold:9" \
  --paths 10000 --seed 42
```

```
配置权重      : A股宽基 8% / 港股 10% / 海外权益 22% / 日本股市 13% / 中国债券 38% / 黄金 9%
组合预期收益  : 4.66%/年（假设值）
组合波动率    : 8.49%/年
外币敞口      : 45%（本币资产 55%）  人民币升值 5% → 组合 -2.25pp ⚠ 超 40%，须在报告中单列汇率敏感性
达成概率      : 89.5%   (10000 条路径, seed=42)
终值分位      : p5 447 / p25 584 / p50 703 / p75 857 / p95 1143 万
判定：达成率 ≥85%，方案稳健。
```

再平衡偏离度：

```bash
python3 scripts/rebalance.py \
  --target "a:8,hk:10,ov:22,jp:13,bond:38,gold:9" \
  --current "a:12,hk:10,ov:9,jp:8,bond:52,gold:9" --total 155 --cash-in 2
```

## 技术特性

- **零依赖**：只用 Python 3 标准库（`argparse` / `json` / `math` / `random`），不需要 numpy、pandas、scipy，装了就能跑。
- **结果可复现**：随机种子固定并写入报告，同一输入永远同一输出。
- **假设显式**：所有收益率、波动率、相关性集中在 `references/asset_classes.md` 一张表里，改一个地方全篇生效。
- **浅色主题**：报告适配浅色界面，涨用红、跌用绿（中国习惯）。

## 文件结构

```
SKILL.md                    七模块流程与执行纪律
manifest.yaml               平台发布元数据
references/
  framework.md              阈值表、评分规则、分桶规则、约束校验、储蓄贡献诊断、达成率与中位数双指标
  risk_profile.md           8 题风险意愿问卷
  asset_classes.md          长期假设表 + 战术指标 + 市场快照（示例格式）
  instruments.md            工具类别与筛选门槛 + 溢价红线 + 建仓阶梯
  rebalance_rules.md        再平衡与复盘规则（按目标权重分档的阈值换算）
scripts/
  monte_carlo.py            达成率测算
  rebalance.py              偏离度与调仓金额
assets/
  ips_template.html         IPS 报告版式模板
```

## 不适用范围

- 机构组合管理、养老目标基金 FOF 的合规测算
- 单一股票研究（请用个股投研类技能）
- 税务筹划（本技能只标注口径，不做税务建议）
- 非人民币资产的跨境架构（QDII 仅到工具类别层面）
